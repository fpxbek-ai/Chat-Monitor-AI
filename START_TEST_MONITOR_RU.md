# Chat Monitor AI — запуск авторизации и мониторинга тестовой группы

> Прочти перед запуском. Это **только тестовый аккаунт**, а не основной рабочий Telegram. Участники тестовой группы должны знать о сохранении сообщений.

## Уже готово

* Код v0.3 содержит безопасный запуск: без двух явных флагов `python main.py` ничего не авторизует.
* Изменения и удаления обрабатываются только для одного разрешённого ID группы после проверки ID тестового аккаунта.
* GitHub Codespaces Secrets должны содержать `CHAT_MONITOR_BOT_TOKEN`, `CHAT_MONITOR_API_ID` и `CHAT_MONITOR_API_HASH`.
* В репозитории есть `monitor_preflight.py` — проверка конфигурации **без Telegram, QR или вывода секретов**.

## Подготовка только в Codespaces

Добавь ещё один **Codespaces user secret** с именем `CHAT_MONITOR_TEST_PHONE` и номером **отдельного тестового** Telegram-аккаунта в международном формате. Разреши доступ только к репозиторию `fpxbek-ai/Chat-Monitor-AI`. Останови и снова запусти Codespace, чтобы секрет подхватился.

В **локальном** `config.ini` проверь:

```ini
[telegram]
user_id = 123456789

[timezone]
name = Asia/Tashkent

[tdlib]
tdjson_path = /usr/local/lib/libtdjson.so
auth_mode = qr

[monitor]
chat_ids = -1001234567890
test_user_id = 987654321
```

**Все числа — примеры.** `user_id` — кому бот присылает уведомления; `test_user_id` — числовой ID аккаунта, который будет сканировать QR; `chat_ids` — единственная разрешённая тестовая группа. Тестовый аккаунт должен быть участником этой группы. Не коммить `config.ini`, SQLite, файлы сессий или ключи.

## Проверка до авторизации

В терминале Codespaces:

```bash
cd /workspaces/Chat-Monitor-AI
git pull --ff-only
python -m unittest -v test_monitor test_safety
python monitor_preflight.py
```

Пока вывод содержит `MISSING`, не запускай авторизацию. Программа выведет подсказки, но не значения секретов.

## После личного подтверждения входа

Только если `monitor_preflight.py` сообщает `READY`:

```bash
python main.py --run-test-monitor --authorize-test-account
```

Отсканируй QR **исключительно отдельным тестовым Telegram-аккаунтом**: Telegram → Настройки → Устройства → Подключить устройство. Никому не передавай QR и коды.

После запуска отправь новое сообщение в тестовой группе, измени его и затем удали. Уведомления должны прийти через созданного бота. Тестирование на реальном Telegram ещё не подтверждено; возможны ограничения событий удаления от Telegram.

Для остановки нажми `Ctrl+C`. GitHub Codespaces может засыпать и не рассчитан на круглосуточную работу. Даже при фильтрации SQLite библиотека TDLib может обрабатывать или кэшировать дополнительные данные, видимые тестовому аккаунту.
