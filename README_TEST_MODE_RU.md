# Chat Monitor AI: проверенный тестовый режим

Мониторинг ограничен одной явно заданной тестовой группой. Основной аккаунт использовать нельзя.

## Что исправлено
- Список группы записан в локальный config.ini; секреты не изменены.
- Общая блокировка сериализует сохранение, редактирование и удаление.
- Повторные события не создают повторных уведомлений.
- HTML экранируется после ограничения текста, без обрыва тегов. В уведомлении показывается до 600 символов каждой версии.
- При ошибке доставки сохранённая версия остаётся для повторного события; автоматической очереди повторной доставки пока нет.
- Исправлена сигнатура native callback TDLib, ссылка на callback удерживается.
- Старые сессии не используются: новый каталог .chat-monitor-test.
- До проверки ID тестового аккаунта обработчики игнорируют сообщения. Несовпадение ID останавливает клиент.
- Исчезающие сообщения и сообщения вне списка не сохраняются. Загрузка медиа отключена.

## Проверка без Telegram
python -m unittest -v test_monitor test_safety
python -m py_compile main.py monitor_store.py tdlib_userbot.py test_monitor.py test_safety.py

Обычный python main.py завершится в SAFE MODE до чтения конфигурации и создания Bot.

## Перед реальной проверкой
В локальной секции [monitor] задайте test_user_id отдельного тестового аккаунта (сейчас 0: запуск заблокирован).
chat_ids должен содержать ровно один отрицательный ID разрешённой группы.
Задайте через защищённое окружение CHAT_MONITOR_TEST_PHONE, CHAT_MONITOR_BOT_TOKEN, CHAT_MONITOR_API_ID, CHAT_MONITOR_API_HASH; при необходимости CHAT_MONITOR_TEST_PASSWORD. Старые phone/password из config.ini не используются.
Не присылайте секреты в чат и не коммитьте config.ini или каталоги сессий.

Только после отдельного подтверждения авторизации запускайте:
python main.py --run-test-monitor --authorize-test-account

Сканируйте QR только отдельным тестовым аккаунтом. После входа проверяется ожидаемый ID.
Флаг --chat-id-only включает отдельный режим команд бота и обращается к Telegram; он не является офлайн-тестом.

Реальная авторизация и доставка уведомлений в Telegram в рамках этой проверки не запускались.
