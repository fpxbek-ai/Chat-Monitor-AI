# Получение ID тестовой группы
Запуск из Codespaces: bash start_chat_id.sh
Дождитесь строки CHAT-ID MODE READY и оставьте процесс работающим.
В тестовой группе отправьте /chatid@ChatMonitorPrivateBot или /id@ChatMonitorPrivateBot.
Команды доступны владельцу из telegram.user_id и явно настроенному monitor.test_user_id.
Команду нужно отправлять от своего аккаунта, не от имени группы или канала.
ID группы берётся из ответа Telegram: нельзя добавлять минус к личному ID.
После преобразования группы в супергруппу ID меняется; запросите его заново.
Обычный python main.py оставляет безопасный режим и не запускает бота.
Режим выдачи ID не запускает TDLib, авторизацию аккаунта или мониторинг сообщений.
При остановке Codespaces обработчик тоже останавливается. После запуска среды выполните команду запуска снова.
Не запускайте несколько обработчиков одновременно: это вызывает конфликт getUpdates.
Ожидающие команды при запуске теперь сохраняются. Поддерживаются /chatid и /id.
