# Chat Monitor AI v0.3 — обновление проекта

Этот архив предназначен для существующего GitHub Codespace `Chat-Monitor-AI` и **не содержит** `config.ini`, токенов, API Hash или Telegram-сессий. Оригинальный `config.ini.exemple` и папка `languages/` остаются на месте.

## Что исправлено

- Сообщения хранятся по **(chat_id, message_id)**, автор хранится отдельно. Исправлена ошибка поиска отредактированных и удалённых групповых сообщений.
- Сохраняются только сообщения из явно разрешённых чатов. Пустой список = **не запускать мониторинг**.
- Добавлен обработчик `updateMessageContent`, чтобы обнаруживать изменения текста, а не только изменение времени редактирования; повторные события дедуплицируются.
- При неопределённом авторе (анонимный администратор / отправка от имени группы) программа не приписывает сообщение случайному пользователю.
- **Нет автоматической пересылки** исчезающих сообщений, фото, видео или документов. В SQLite остаётся лишь текст/подпись и отметка о типе медиа.
- Бот уведомлений доступен только указанному владельцу для команд `/start` и `/chatid`.
- История сохраняется в новой таблице `monitored_messages_v3` внутри уже исключённого из Git файла `messages.db`. Старая таблица и прежняя база не удаляются. Очистка записей старше 30 дней.
- Регистрация обработчиков происходит **до** Telegram-авторизации. Разрешённые ID задаются в локальном `config.ini`.
- Добавлен режим получения ID тестовой группы, не подключающий Telegram-клиент TDLib.

## Замена файлов в браузерном GitHub Codespaces

**1.** Скачай `Chat-Monitor-AI-v0.3.zip` из диалога и перетащи его в панель файлов Codespaces (`/workspaces/Chat-Monitor-AI`). Секреты и `config.ini` не загружай.

**2.** Открой терминал в корне проекта и выполни **по очереди**:

```bash
cd /workspaces/Chat-Monitor-AI
mkdir -p /workspaces/chat-monitor-backup
cp main.py tdlib_userbot.py /workspaces/chat-monitor-backup/
python -m zipfile -e Chat-Monitor-AI-v0.3.zip .
python -m unittest discover -p 'test_*.py' -v
python -m py_compile main.py tdlib_userbot.py monitor_store.py
```

Ожидаемый результат: **4 tests / OK**, отсутствие ошибок синтаксиса. Это офлайн-тесты логики, **не подтверждение совместимости с реальным TDLib**.

**3.** Для получения ID собственной тестовой группы (без пользовательской Telegram-сессии):

```bash
python main.py --chat-id-only
```

Добавь созданного бота в свою тестовую группу, отправь `/chatid` (при необходимости `/chatid@ИмяТвоегоБота`), получи отрицательный ID. Останови помощник командой `Ctrl+C`. Включать бота в рабочие группы не нужно.

**4.** В локальный `config.ini` допиши в конец:

```ini
[monitor]
chat_ids = "-1001234567890"
```

Число выше **только пример**: замени его настоящим ID тестовой группы. Если группа изменит тип (миграция в супергруппу), её ID может измениться. Сначала проверь в режиме помощника.

Для QR-авторизации в существующем разделе `[tdlib]` должны оставаться:

```ini
tdjson_path = "/usr/local/lib/libtdjson.so"
auth_mode = "qr"
```

Остальные Telegram-секреты читаются из трёх существующих Codespaces Secrets: `CHAT_MONITOR_BOT_TOKEN`, `CHAT_MONITOR_API_ID`, `CHAT_MONITOR_API_HASH`.

**5.** Перед авторизацией тестового аккаунта убедись, что в группе участники согласны на сохранение сообщений. Затем, когда готов, запусти:

```bash
python main.py
```

На экране появится QR для входа **тестового** аккаунта. Никому не пересылай QR-ссылку. Проверь сообщение, изменение и удаление в тестовой группе.

## Границы и ограничения

- Программа **не восстанавливает** сообщения, которых никогда не получала, и не всегда получает события удаления (зависит от Telegram и типа чата). Она не может определить, кто нажал «Удалить», если Telegram это не сообщает.
- TDLib **сама ведёт локальный кэш** Telegram-аккаунта. Фильтр в нашей SQLite не означает, что TDLib вообще не получает или не кэширует прочие доступные аккаунту чаты. Поэтому настоятельно рекомендуется отдельный тестовый аккаунт без доступа к служебным данным.
- В Codespaces монитор работает только пока Codespace активен; это не VPS 24/7.
- Мы проверили синтаксис и логику офлайн, но **реальную QR-авторизацию и TDLib в твоём Codespaces не проверяли**. При ошибке пришли текст без ключей и QR-ссылок.
- Не загружай личные файлы сессии в GitHub и не выкладывай сохранённые сообщения в публичный репозиторий.
